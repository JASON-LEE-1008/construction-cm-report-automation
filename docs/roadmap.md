# Roadmap

## Near term

- Add Excel import support for `.xlsx` files.
- Add bilingual Korean/English report templates.
- Add unit consistency checks.
- Add report sections for assumptions and excluded items.

## Mid term

- Add optional OpenAI API-assisted report review.
- Add a prompt package generator for Codex-assisted implementation tasks.
- Add GitHub Issue export for review action items.
- Add richer construction categories for material, labor, equipment, subcontract, and indirect costs.

## Long term

- Add comparison profiles for public bid review, change-order preparation, and monthly CM reporting.
- Add structured JSON report output.
- Add a lightweight web UI while keeping the CLI as the core workflow.

## Project principles

- Keep the offline workflow usable without paid API calls.
- Keep all sample data synthetic.
- Keep calculations transparent and testable.
- Do not overstate adoption or project maturity.
